# Voice Studio

Бесплатная локальная студия нейросетевой озвучки для Windows 11. Цель – естественная русская речь, эмоциональная озвучка диалогов, аудиокниги и клонирование собственного/разрешённого голоса.

> Статус на 2026-11-14: **только спецификация**, программа и модели ещё не реализованы и не протестированы. Это не готовый продукт.

## Принципы
- Полностью бесплатный локальный сценарий; **никаких платных моделей, подписок и обязательных облачных API**.
- Несколько подключаемых открытых TTS-движков: можно сравнивать результаты.
- Приоритет качества русской речи, интонаций, пауз, диалогов.
- Неограниченный размер исходных документов; внутри – генерация небольшими частями, с сохранением и возобновлением.
- Разметка эмоций/персонажей в тексте, включая уровень intensity; возможности конкретных моделей могут различаться.
- Клонирование только собственного голоса или голоса с разрешения.
- Коммерческий экспорт только после подтверждённой проверки лицензии **конкретной версии весов** и условий на выходное аудио.
- Безопасный релиз Windows: не обходить Smart App Control/Code Integrity.

## Целевое оборудование
Windows 11 Pro · NVIDIA RTX 4060 Ti 8 GB VRAM · Ryzen 5 3600 · 16 GB RAM. Требуются тесты совместимости, скорости и VRAM; более крупные модели – только с измеренной оптимизацией.
