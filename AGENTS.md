# AGENTS.md – правила разработки Voice Studio

Сначала прочитать README.md и docs/01-product.md…docs/07-roadmap.md. Документация отражает согласованный продукт; менять фундаментальные требования только явно и с ADR.

## Не нарушать
- Zero budget: **без платных моделей, подписок и обязательных API/серверов**.
- Offline-first Windows 11, русский язык, RTX 4060 Ti 8 GB. Не обещать производительность без замеров.
- Подключаемые движки; модельный код не должен проникать в UI.
- Чужие голоса – только с разрешения; запрещено публиковать голосовые образцы и личные книги в GitHub.
- Не внедрять обход Windows Smart App Control/Code Integrity/Defender; сначала минимальный smoke.
- Не маркировать коммерческое использование разрешённым без ревизии checkpoint, лицензии весов, кода, codec, зависимостей и результатов.
- В коммерческом режиме блокировать NONCOMMERCIAL_ONLY, REVIEW_REQUIRED и BLOCKED, включая смешанный export.
- Теги Voice Studio не выдавать за универсальные «родные» функции TTS: проверять возможности каждого адаптера.
- Никаких фиктивных метрик и PASS без реальных тестов.

## Режим выполнения инженерных задач
Для каждой реализуемой функции: production-код, минимальные автоматические тесты, воспроизводимые инструкции, smoke-проверка и запись ограничений. При проблемах с Windows фиксировать точные диагностические сведения; не просить отключить безопасность. Защищать существующие файлы и не перезаписывать пользовательские данные.
