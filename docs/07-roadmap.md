# Дорожная карта и критерии приёмки

**Статус:** техническая документация, не реализация. Бюджет = 0 ₽; коммерческая безопасность – P0.

## Этап 0. Проверка платформы и прав
- [ ] Минимальный PySide6 EXE + проверка Windows Smart App Control/Code Integrity.
- [ ] CUDA/PyTorch обнаружение RTX 4060 Ti, VRAM 8 ГБ, RAM 16 ГБ.
- [ ] Зафиксировать список допустимых официальных checkpoint и их immutable revisions, полный license-gate.
- [ ] Принять матрицу тестовых русских текстов без личных рукописей.

## Этап 1. Рабочий вертикальный срез
- [ ] Ввод/вставка русского текста, загрузка Qwen3-TTS 0.6B Base.
- [ ] Озвучивание, WAV/MP3 и проигрывание; отображение ошибок, времени, peak VRAM.
- [ ] Драйвер выгрузки модели, очередь, отмена, базовый кеш.
- [ ] Первая проверка клонирования разрешённого голоса.

## Этап 2. Каталог движков и лицензий
- [ ] Реестр моделей; добавление Qwen3 1.7B при подтверждённом тесте VRAM.
- [ ] Кандидаты Chatterbox Multilingual V3 и CosyVoice 3 по результатам проверки.
- [ ] Коммерческий режим и запрет неразрешённых/непроверенных моделей.
- [ ] Локальное сравнение A/B, журнал метрик качества и производительности.
- [ ] Автоматические тесты licence-gate для генерации, объединения и экспорта.

## Этап 3. Эмоции, персонажи, книги
- [ ] Parser эмоциональных тегов, preview и валидатор.
- [ ] Поддержка голосов персонажей, профилей клонирования.
- [ ] Импорт TXT/DOCX/EPUB, главы и очередь длительной генерации.
- [ ] Сохранение прогресса после падения, выбор дублей, точечная регенерация.
- [ ] Склейка, паузы, нормализация громкости, экспорт глав/книги.

## Этап 4. Качество и Windows-распространение
- [ ] Слепое сравнение качества русского текста и клонирования на целевой машине.
- [ ] Испытание длинного проекта (не менее 500 000 символов), сохранность после остановки.
- [ ] Smoke-тест EXE на Windows с включённой защитой; диагностировать, а не обходить блокировки.
- [ ] Инструкции по локальной установке, удалению моделей/голосов, backup проекта.
- [ ] Подготовка честного списка поддерживаемых функций каждой модели.

## Приёмочные сценарии (не отмечать PASS без фактического теста)
1. Озвучить короткую фразу на русском, послушать, сохранить WAV+MP3, сверить содержимое.
2. Проверить ударения, имена, числа и паузы на фиксированном корпусе.
3. Создать голос по разрешённому образцу, повторно открыть проект и получить узнаваемый голос (слепая оценка).
4. Разметить один диалог тегами, увидеть частично/полностью неподдерживаемые возможности.
5. Генерировать длинную книгу, принудительно завершить процесс и продолжить без потери готовых сегментов.
6. Поменять одну фразу и проверить, что кеш остальных сегментов сохранён.
7. Включить «Коммерческий режим» и убедиться, что XTTS-v2/F5-TTS pretrained, UNKNOWN и смешанные записи не проходят экспорт.
8. Подменить model revision / license manifest и убедиться, что коммерческий статус сбрасывается.
9. Запустить на Windows 11 без отключения защиты, зафиксировать точные диагностические данные при блокировке.
10. Показать в UI нагрузку VRAM и обработать OOM без потери проекта.

## ADR: зафиксированные решения
- ADR-001: локальный бесплатный продукт, исключить платные модели, подписки и облачный API как обязательную функцию.
- ADR-002: движки сменные, никакой привязки всей программы к одному TTS.
- ADR-003: лицензирование «fail closed», отделить код/веса/выходное аудио.
- ADR-004: пользовательские теги – язык Voice Studio, а не универсальный родной синтаксис движков.
- ADR-005: без искусственного лимита на книгу; внутренние небольшие сегменты + checkpointing.
- ADR-006: голосовой образец хранится локально и используется с разрешения.
- ADR-007: Windows security не обходить; проверять до разработки сложной сборки.

## Открытые исследования
Качество Qwen/Chatterbox/CosyVoice на русском, потребление VRAM 1.7B, корректность «эмоций» по модели, точные версии dependency, реальная стабильность 500k+, поддержка локального EXE при текущих защитных настройках.
