# Модельный каталог и стратегия выбора

Не привязывать Voice Studio к одной модели. Каждая интеграция – сменный адаптер с отчётом о возможностях и статусе лицензии конкретного checkpoint.

## Кандидаты

| Модель / вариант | Для чего | Ограничения и статус |
| --- | --- | --- |
| Qwen3-TTS 12Hz 0.6B-Base | Быстрый первый прототип клонирования | Русский поддерживается; точная производительность на RTX 4060 Ti не измерена; лицензия checkpoint Apache-2.0 указана на официальной карточке |
| Qwen3-TTS 12Hz 1.7B-Base | Кандидат высокого качества клона | Может потребовать оптимизации VRAM; замерить |
| Qwen3-TTS CustomVoice 0.6B/1.7B | Готовые голоса и управление речью | Не путать с Base: режимы/API отличаются |
| Qwen3-TTS VoiceDesign 1.7B | Создание голоса по описанию | Не заменяет клонирование по образцу; тестировать отдельно |
| Chatterbox Multilingual V3 | Эмоциональность и многоязычное чтение | Русский заявлен, код MIT; **проверить лицензию весов/вспомогательных частей**, проект с августа 2026 не сопровождается |
| CosyVoice 3 | Диалоги, стиль и голосовой образец | Проверить отдельную версию, русский, установку, правовой статус точных весов |
| XTTS-v2 | Эталон сравнения клонирования | Веса Coqui Public Model License: **только некоммерчески**, включая результаты |
| F5-TTS | Эталон клонирования/адаптации | Код MIT, официальные предобученные веса CC BY-NC 4.0 – коммерческий режим запрещён |
| Silero TTS | Быстрая русская озвучка | Статус зависит от конкретных весов/версии; без верификации коммерчески недоступна |

Список кандидатов не является списком уже протестированных/установленных моделей. Любые community fine-tunes – отдельная запись, отдельная лицензия и отдельный benchmark.

## Первое сравнение
- Qwen3-TTS 0.6B Base как стартовый технический прототип.
- Qwen3-TTS 1.7B Base – добавить при успешной загрузке в 8 ГБ VRAM.
- Chatterbox Multilingual V3 – добавить как альтернативу после проверки официальных весов и поддержки Windows.
- CosyVoice 3 – исследовательский кандидат; не утверждать без тестов.
- XTTS-v2 и F5-TTS по умолчанию исключать из коммерческого режима.
- Silero – только после проверки точного checkpoint.

## Тестовый корпус для русского
Нейтральный рассказ, тревожный диалог, сдержанная грусть, крик, шёпот, сложные ударения, имена, аббревиатуры, числа, даты, длинная фраза и 20-минутный непрерывный проект. Использовать специально придуманный тестовый текст, а не личные рукописи в публичном git.

## Оценка
Проводить слепое A/B-прослушивание, считать ошибки произношения, наличие пропусков/повторов, стабильность тембра, отличие в громкости между фрагментами, качество клона, пиковую VRAM, RTF (секунды генерации / секунды аудио), RAM и потребление диска. Результаты фиксировать по версии модели и параметрам.
