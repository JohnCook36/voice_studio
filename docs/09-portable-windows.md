VOICE STUDIO – PORTABLE WINDOWS (альфа)

Запуск:
1. Скачайте архив VoiceStudio-Windows-Portable-x64 из GitHub Actions.
2. Распакуйте ПОЛНОСТЬЮ в отдельную папку, например C:\\VoiceStudio.
3. Откройте VoiceStudio.exe в этой папке. Не перемещайте EXE отдельно от папки _internal.
4. Нажмите «Модели: скачать / удалить». Выберите Qwen3-TTS 0.6B CustomVoice и загрузите модель. Нужны интернет и место на диске (несколько ГБ).
5. Введите текст, выберите голос, сохраните WAV. Для MP3 пока требуется FFmpeg.
6. Ненужные модели удаляются в том же окне; отображается занимаемый объём. Голоса, книги и внешние директории программа не удаляет.

Важно:
- Python и PyTorch вручную устанавливать не требуется: они упакованы вместе с Portable EXE.
- Скачанные модели хранятся отдельно в %LOCALAPPDATA%\VoiceStudio\models и не пропадают после обновления EXE.
- Библиотеки и сам EXE не подписаны коммерческим сертификатом. Smart App Control/Code Integrity могут блокировать их. Не отключайте защиту ради запуска.
- CI проверяет запуск окна на Windows в тестовом окружении, но не доказывает успешную CUDA-генерацию и запуск на вашем ПК.
- Коммерческий режим заблокирован, пока лицензии точных версий весов и зависимостей не проверены.
- Это alpha-версия. Не публикуйте коммерческие озвучки на её основе до аудита лицензий.
