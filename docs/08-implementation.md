# Первый программный срез – 0.1.0a1

**Реализовано в ветке feature/mvp-voice-core:** графический редактор PySide6, TXT/DOCX, выбор Qwen3-TTS Base/CustomVoice 0.6B/1.7B, работа с локальными весами или явное подтверждение загрузки, WAV/MP3 (MP3 требует FFmpeg), клонирование собственного разрешённого голоса по WAV и расшифровке, теги, фрагментный рендер с кешированием/возобновлением, отмена между фрагментами, provenance и блокировка коммерческого экспорта непроверенных моделей, unit-тесты и минимальный UI smoke CI.

**Не реализовано:** EPUB, библиотека профилей голосов, Chatterbox/CosyVoice/Silero, несколько разных голосов внутри одной главы, авторазметка, полная библиотека книг, собранный EXE, аппаратный GPU smoke и полный коммерческий аудит весов.

## Запуск Windows 11 (PowerShell)

1. Установить Python 3.12 x64 и рабочий NVIDIA драйвер.
2. В корне репозитория:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[gui]"
python -m voice_studio --smoke
```

3. Для нейросетевой озвучки установить CUDA-совместимый PyTorch [по официальной инструкции](https://pytorch.org/get-started/locally/), затем `python -m pip install -e ".[qwen]"`. Проверить `python -c "import torch; print(torch.cuda.is_available())"` (ожидается `True`). Официальный пакет: https://github.com/QwenLM/Qwen3-TTS.
4. Запустить `python -m voice_studio`. Выбрать **0.6B-CustomVoice**, голос Ryan/Serena, при необходимости подтвердить загрузку весов (несколько ГБ) или указать уже скачанную папку. Для MP3 установить FFmpeg в PATH.
5. Для **0.6B-Base** указать собственный WAV-образец, точную расшифровку и подтвердить разрешение владельца голоса.

## Известные ограничения и открытые проверки

- Готовые голоса Qwen не являются носителями русского языка по умолчанию и могут иметь акцент. Качество оценивается на слух.
- Из эмоциональных инструкций в текущем адаптере поддерживается только CustomVoice 1.7B. 0.6B и Base сообщают о неподдерживаемых тегах; интенсивность пока не переводится в реальный параметр модели.
- Тег speaker у Base сейчас только метка: используется один образец на запуск, разные голоса персонажей пока не подключены.
- Фрагменты лежат в .voice_studio_cache рядом с экспортом; автоматической уборки кеша нет.
- У всех встроенных моделей статус лицензии REVIEW_REQUIRED, так что коммерческая генерация заблокирована до проверки точного чекпойнта и всех зависимостей. Это **не** утверждение, что Qwen запрещает коммерческую генерацию.
- --smoke подтверждает лишь запуск окна, не доказывает работу PyTorch/CUDA или совместимость неподписанного EXE с Smart App Control.
- CI не скачивает веса и не проверяет фактический звук. Нужны испытания на RTX 4060 Ti 8 ГБ.
