# Облегчённый установщик Voice Studio

## Принцип

Вместо архива на 4,9 ГБ предлагается маленький файл VoiceStudioSetup.exe. В нём находятся только графический интерфейс первого запуска, менеджер окружений uv и исходный код Voice Studio. PyTorch, CUDA, PySide6, Qwen-TTS и веса моделей не включены.

## Что он проверяет

- Уже установленное рабочее окружение Voice Studio: %LOCALAPPDATA%\VoiceStudio\runtime\.venv.
- Совместимый Python 3.12 x64, найденный на компьютере.
- PySide6, huggingface_hub, Qwen-TTS, PyTorch и поддержку CUDA в выбранной среде.
- Наличие полного совместимого стороннего окружения, которое можно выбрать вручную и использовать без переустановки.
- Уже загруженные библиотеки и пакеты в кеше менеджера uv.

Если Python отсутствует, uv скачивает отдельный управляемый Python. Библиотеки ставятся в отдельную папку Voice Studio без изменения общесистемной установки. Если совместимая среда уже готова, ничего повторно скачивать не требуется. Отдельные модули из разных случайных Python-сред не смешиваются.

## Два этапа установки

1. По умолчанию – облегчённая установка интерфейса и менеджера моделей.
2. Галочка «Установить также Qwen-TTS и CUDA» – установка тяжёлого GPU-движка, необходимого для генерации. Интернет нужен только при отсутствии необходимых компонентов.

После установки моделей в интерфейсе Voice Studio можно видеть объём и удалять конкретные модели, не затрагивая рукописи и голосовые профили. Удаление модели освобождает её собственную папку; CUDA/PyTorch удаляются отдельно, если будут добавлены соответствующие функции.

## Безопасность и ограничения

- Запрос подтверждения перед скачиванием библиотек и модели.
- Источники: PyPI, официальный индекс PyTorch, uv и его управляемые дистрибутивы Python.
- Не устанавливаются системные пакеты, не изменяется PATH, не отключается Smart App Control.
- Неподписанный EXE всё ещё может быть заблокирован Windows.
- Реальный CUDA inference на RTX 4060 Ti не тестировался на пользовательском устройстве.
- Коммерческая генерация на непроверенных версиях модели по-прежнему заблокирована.
