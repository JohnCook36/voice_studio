# Windows 11, установка, безопасность

## Почему это P0
Предыдущая локальная программа распознавания аудио/видео на этой машине запускалась в версии 1.3.0, но сборка 1.4.0 блокировалась; фиксировался статус NotSigned и Code Integrity. Точная причина блокировки не доказана одной строкой NotSigned. Нельзя обещать, что другой упаковщик решит проблему.

## Релизная политика
- Не предлагать отключать Smart App Control, Defender, Code Integrity или обходить системную защиту.
- Упаковка PyInstaller one-file/one-folder или Nuitka **не гарантирует** прохождение политики Windows.
- До крупной реализации сделать минимальное приложение PySide6 и проверить запуск без подписи, Smart App Control, Defender, Code Integrity и карантин/журналы.
- Отдельно проверить сборку с CUDA/PyTorch и потом TTS-весами.
- Без покупки сертификата не обещать universally installable EXE. Предусмотреть честный альтернативный способ запуска из проверенного исходного кода/официального Python, если разрешено политиками ПК.
- Распространять проверки hash/SHA-256 и список содержимого релиза; CI сборки и smoke-тесты.
- Не смешивать скачивание модели с запуском неизвестного стороннего кода из интернета.

## Диагностика проблем
1. Зафиксировать точное сообщение и название заблокированного файла.
2. Проверить статус Smart App Control, Protection History, Event Viewer → Applications and Services Logs → Microsoft → Windows → CodeIntegrity → Operational.
3. Проверить происхождение файла, подпись, контрольную сумму и карантин.
4. Выяснить, блокируется ли минимальный оконный EXE или только пакет с библиотеками.
5. Исправить причину и регрессионно проверить на той же машине.

## Меры безопасности
- Образцы голоса и тексты остаются локальными; никаких скрытых аналитик и загрузок.
- Локальные записи не попадают в Git, GitHub Actions, issue logs, облачный crash reporting или диагностические архивы.
- Загрузки моделей только из разрешённых источников с проверкой hash/версии/лицензии.
- Не допускать небезопасную десериализацию недоверенных чекпойнтов и произвольное выполнение кода из папки модели.
- Пользователь видит размер загрузки, источники, место хранения, согласие на голос, функцию удаления.
- Не хранить необязательные секреты, сохранять provenance без содержания референс-записей.
- Публичный репозиторий: никакого личного аудио, файлов книг, логов с личными данными и больших бинарных моделей.
